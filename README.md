# Assignment 2 · 3D 交互个人主页（白名睿）

《新媒体交互设计》第 2 次作业：**制作一个 3D 交互的个人主页，展示个人简历、自己的作品等内容**。

## 在线访问

<https://bai1971.github.io/assignment2/>

## 亮点

- **真 3D 场景**：Three.js 打造的漂浮几何体（实体 + 线框双层）、中央展示台、粒子星尘，支持**鼠标拖拽旋转**与**视差跟随**
- **中央几何雕塑**：多面体核心 + 线框护壳 + 双轨道环，悬浮于展示台上方持续自转浮沉，是页面的 3D 主视觉
- **四大板块轮播**：关于我 / 荣誉 / 作品 / 技能，左右箭头或键盘 ←→ 切换，**背景色、幽灵大字、3D 场景主色**同步 650ms 过渡（呼应老师样板页"背景配色联动变化"）
- **作品直达**：顶部与右下角链接可一键跳转第 1 次（名著视频）、第 4 次（悬疑 PPT）作业
- 支持 `?s=2` 这样的 URL 参数直达指定板块

## 技术

- 单文件 `index.html` + 本地 `vendor/three.min.js`（Three.js r128，无 CDN 依赖，部署稳定）
- 纯前端实现，GitHub Pages 直接部署
