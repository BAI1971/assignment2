# Assignment 2 · 3D 交互「个人博客」首页（白名睿）

《新媒体交互设计》第 2 次作业。**用 3D 交互的方式呈现个人内容**：这一版做成博客首页，文章流是主角，3D 场景负责氛围与分类反馈。

## 在线访问

- 3D 博客首页：<https://bai1971.github.io/assignment2/>
- 传统静态博客（作业 3）：<https://bai1971.github.io/assignment3/>

## 亮点

- **真 3D 场景**：Three.js 打造的漂浮几何体（实体 + 线框双层）、中央展示台、粒子星尘，支持**鼠标拖拽旋转**与**视差跟随**
- **中央几何雕塑**：多面体核心 + 线框护壳 + 双轨道环，悬浮于展示台上方持续自转浮沉；**页面不含任何人物形象**
- **文章流 + 分类联动**：左侧 6 篇文章按分类筛选，切换到「课程笔记 / 作品手记 / 校园现场 / 生活随笔」时，**背景色、幽灵大字、3D 材质与灯光主色**一起过渡
- **摘要卡**：点选文章后右侧卡片显示摘要、标签与「阅读全文」，一键跳到作业 3 的对应博文详情页
- **导航互通**：顶部归档 / 关于 / RSS 直达传统博客，右下角可切换回传统版
- 支持 `?s=1` 这样的 URL 参数直达指定分类，便于逐屏核验

## 技术

- 单文件 `index.html` + 本地 `vendor/three.min.js`（Three.js r128，无 CDN 依赖，部署稳定）
- HTML / CSS / JS 均带结构注释；原生 JS，无框架、无构建步骤
- 纯前端实现，GitHub Pages 直接部署
